# Alien Invasion 🚀 - Python Game<br>
Alien Invasion is an interactive shooting game built with Python and Pygame, with a Flask-based web interface for launching the game.<br>

The player controls a spaceship, moves it left and right, and shoots lasers to destroy incoming aliens. The game includes scoring, increasing difficulty, game-over handling, and restart functionality.<br>
## ✨ Features<br>

## 🚀 Game Interface<br>

● Interactive web-based launch page<br>
● Play Game button to start the game<br>
● Return to Desktop option<br>
● Instructions for game controls<br>

## 👽 Alien Invasion Gameplay<br>
● Control the spaceship using keyboard controls<br>
● Move the ship left and right<br>
● Fire lasers to destroy aliens<br>
● Aliens move across the screen and gradually move downward<br>
● New alien fleets are created after clearing the current fleet<br>

## 🎯 Scoring System<br>
● Points are awarded for destroying aliens<br>
● Scoreboard displays the current score<br>
● High scores are tracked during gameplay<br>

## 💥 Game Over & Restart<br>
● Game ends when an alien reaches the ship or bottom of the screen<br>
● Try Again button allows the player to restart<br>
● Home button returns to the main game screen<br>

## 🎨 Game UI<br>
● Dark arcade-style interface<br>
● Neon-themed colors<br>
● Glowing spaceship, alien, and laser effects<br>
● Styled game-over and start screens<br>

## 🌐 Flask Web Interface<br>

Flask provides the web interface and handles game launching through a dedicated route.<br>

● Displays the main game page<br>
● Launches the Pygame application<br>
● Returns success or error messages when launching the game<br>

## 🛠️ Built With<br>
● Python<br>
● Pygame<br>
● Flask<br>
● HTML5<br>
● CSS<br>
● JavaScript<br>
